# Josh Vanderspuy

**Service is the new software.** I'm working toward forward-deployed engineering: sit with the problem, ship the tool, keep it running.
Most of what's here comes from real work on Spanish electricity data and AI agent tooling.

## Shipped
- **[Spain power prices](https://jvanders22.github.io/spain-power-prices/)** ([repo](https://github.com/jvanders22/spain-power-prices)): OMIE prices vs REE renewables, with a notebook and an interactive dashboard, refreshed by CI.
- **[Spain negative-price alert](https://jvanders22.github.io/spain-negative-price-alert/)** ([repo](https://github.com/jvanders22/spain-negative-price-alert)): a daily alert for zero or negative Spanish day-ahead prices, with history, a JSON/RSS feed and a calendar.
- **[Spain battery payback](https://jvanders22.github.io/spain-battery-payback/)** ([repo](https://github.com/jvanders22/spain-battery-payback)): will a home battery pay for itself? It replays every hour of 2025 in the browser, and every assumption can be edited.
- **[spend-gate](https://github.com/jvanders22/spend-gate)**: a local policy gate for paid agent calls that decides before anything is signed.

## Stack
Python (pandas), TypeScript, Vite, Observable Plot, GitHub Actions and Pages, and AI agents (Claude Code, Codex).
